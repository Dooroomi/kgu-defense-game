# 경기대 학점 디펜스 (KGU Credit Defense)

경기대 학점 디펜스는 밀려드는 과제와 시험, 논문으로부터 학점을 지켜내고 무사히 졸업하는 것을 목표로 하는 Pygame 기반 타워 디펜스 게임입니다.

---

## 1. 실행 및 필수 라이브러리 설치

본 게임을 실행하려면 Python 3.x 환경과 `pygame-ce` 라이브러리가 필요합니다.

### 패키지 설치
`pygame_defense` 폴더로 이동한 후 아래 명령어를 입력하여 필수 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```

### 게임 실행
설치가 완료되면 아래 명령어로 게임을 실행할 수 있습니다.
```bash
python main.py
```

---

## 2. 게임 조작법

| 입력/조작 | 기능 및 설명 |
| :--- | :--- |
| **마우스 좌클릭** | • 우측 상점 패널에서 연구 항목(타워/트랩) 선택<br>• 맵 위의 도로 외 구역에 타워 배치 (트랩은 도로 위에도 가능)<br>• 배치된 타워를 클릭하여 강화(Lv. Up) 및 판매(Sell) 팝업 기동<br>• 버튼 및 메뉴 선택 |
| **마우스 우클릭** | • 현재 선택 중인 타워/트랩의 배치 모드 취소 |
| **스페이스바 (SPACE)** | • 학기(웨이브) 시작 (대기 상태인 `WAITING` 혹은 `COMPLETED` 시 사용) |
| **F11** | • 전체 화면 모드 / 창 모드 토글 (해상도 자동 스케일링 지원) |
| **ESC** | • 인게임 플레이 도중 게임 종료 및 메인 화면 이동 |

---

## 3. 이스터에그 (치트코드) 사용법

게임 시작 후 **타이틀(메인) 화면**에서 키보드로 아래의 영어 비밀코드를 직접 타이핑하면 치트 효과가 즉시 발동되어 보스전으로 건너뜁니다. (입력 중인 단어는 화면 하단에 표시되며, `BACKSPACE`로 수정할 수 있습니다.)

* **`lovepeace` (이지 보스전)**
  * 난이도를 **EASY**로 설정
  * 즉시 5단계(보스전)로 건너뜀
  * 초기 재화(장학금) **150,000원** 지급
  * 맵 전체 초기화 후 대기(`WAITING`) 상태로 전환 및 보스 BGM 재생
* **`loveprof` (노멀 보스전)**
  * 난이도를 **NORMAL**로 설정
  * 즉시 5단계(보스전)로 건너뜀
  * 초기 재화(장학금) **150,000원** 지급
  * 맵 전체 초기화 후 대기(`WAITING`) 상태로 전환 및 보스 BGM 재생
* **`lovedemon` (하드 보스전)**
  * 난이도를 **HARD**로 설정
  * 즉시 5단계(보스전)로 건너뜀
  * 초기 재화(장학금) **150,000원** 지급
  * 맵 전체 초기화 후 대기(`WAITING`) 상태로 전환 및 보스 BGM 재생
